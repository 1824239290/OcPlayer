# macOS UI 对齐约定

Windows 前端以 macOS OcPlayer 的现有界面为准。保留页面结构、内容顺序、尺寸、间距、导航、控件排列及交互，不自行添加主推横幅、大标题、宣传文案、推荐模块或改换卡片形态。

平台实现差异不能成为重新设计界面的理由。发现无法直接还原的能力时，说明具体限制、影响及可选实现，由用户决定取舍。之前 `WINUI3-FRONTEND-PLAN.md` 中主动提出的布局变化仅为早期建议，与本约定冲突时以本约定为准。

## 当前 Demo 的对齐范围

- Windows 播放时，HUD 收起会同步隐藏窗口内系统光标和原生标题栏控件；鼠标移出窗口也会收起 HUD，显示 HUD 或退出播放器时恢复窗口状态。
- 首页按用户提供的 macOS 截图对齐：紧凑图标导航、页面/账号信息、文件入口、刷新和搜索在同一顶栏。
- 左上角按用户选择改用 WinUI 3 `NavigationView` 顶部模式，显示系统默认的底部选中指示线，不显示外层药丸框。三个入口各 40 DIP，总宽 120 DIP，均使用原生图标槽，保证选中线宽度与位置一致，取消默认自定义内容区域的 48 DIP 留位。头像按 macOS `AppShellChrome.swift` 的 `SectionAvatarIcon` 显示为 18 DIP 圆形、等比填满：首页选中保留原色，其余分区灰化；观影与设置用图标亮暗区分选中态，悬停及键盘焦点保留系统反馈。
- 内容顺序：继续观看 → 最近添加 → 媒体库 → 接下来看；留白及横向卡片按参考比例实现。
- 继续观看使用 328×184.5 DIP 横图；最近添加使用 230×129.375 DIP 横图。标题、S/E、剩余时长和细进度标记在图下。
- 媒体库卡按 macOS `LibraryCard` 显示库自身的 Primary 封面，不叠加库名或压暗遮罩；下方显示名称和库类型。库没有封面时最多使用四张内容海报：一张铺满、两张并排、三张上二下一、四张 2×2，各格等比裁切且不留缝。合集库从最多四个合集的成员中轮转取海报，仍无图时显示占位图标。
- Home fixture 的图片仅裁取用户参考截图中的媒体图像及头像，界面本身由原生 WinUI 控件构成。所有浏览页面共用会话级背景轮播；背景实现以 GitHub macOS `888ccdd` 的 `BACKGROUND-ARCHITECTURE.md` 与 `AMBIENCE.md` 为准。
- 显式 Demo 模式保留静态画面与模拟时钟。默认模式已接入共享 Core 与 Erika Windows 原生播放，见 [组合说明](core-integration.md)。
- 真实播放已接通 OcPlayer 弹幕网关：自动识别、手动搜索的作品 → 剧集两层选择、重新匹配、本地导入、时间偏移和共用设置；弹幕由 Erika 渲染，设置即时生效。功能及实机验证见 [DANMAKU-INTEGRATION.md](DANMAKU-INTEGRATION.md)。
- 播放器覆盖同一个主窗口，返回时恢复原页面与滚动位置；全屏也复用主窗口。HUD 保留 macOS 的控件分区；左上采用与二级页面一致的标题栏返回按钮，全屏紧邻返回，音量入口紧邻右上最小化，点击后弹出原生滑块与数值，中央播放/跳转和底部标题/菜单/进度位置保持不变，使用 WinUI 原生按钮、Slider 与 MenuFlyout；HUD 显示时覆盖与 macOS PlayerHUDReadabilityScrim 一致的全画面 32% 黑色遮罩，隐藏时完全移除；中央三个播放控件无底板，跳转使用浅弧箭头与秒数；标题栏三个按钮沿用 WinUI 默认悬停和按下效果，次要功能按钮仅在悬停和聚焦时突出。
- HUD 对照当前 macOS 源码使用 200ms 显隐、播放中闲置 3 秒收起、单击画面切换显示、双击全屏；手动收起后移动鼠标不重新唤出。菜单、进度拖动和键盘控件焦点会保持 HUD，操作结束重新计时；字幕不随 HUD 消失。标题区显示剧名与“集号 · 单集名”，电影不显示多余小标题，窄窗口缩小间距。轨道使用原生单选状态，弹幕开关反映实际选择。字幕字号已接 Erika 的 `setSubtitleScale`，章节通过共享 Core 的 `browse.chapters` 获取；此前“缺少接口”的说明不成立，不能只根据 C# 是否已有封装判断底层能力。
- 已基于 2026-11-15 的实机截图补齐媒体库、详情首屏、观影模块、设置总览与十个子页，以及播放器 HUD。完整验证、素材来源和尚存差异见 [`DEMO-VALIDATION.md`](DEMO-VALIDATION.md)，这些页面仍不代表完整功能验收。
- 浏览页面的转场对照 macOS `888ccdd` 的 `AppDesignKit/Motion.swift`、`AppShell.swift` 与 `DetailPagePager`：首页、观影、设置之间使用 0.2 秒交叉淡变；进入及返回媒体库、详情、设置子页使用 0.45 秒退场、0.05 秒恢复前置拍、0.45 秒入场。详情两屏使用 0.45 秒前景淡出、0.55 秒模糊遮罩扩张/收回、延迟至 0.6 秒的 0.4 秒前景淡入；固定背景全程保留。系统关闭动画时立即切换。
- 详情第二屏保留原生纵向滚动，滚到顶部后继续向上滚动返回首屏；左上角返回也先回首屏，再返回来源页。滚轮处理观察 `ScrollViewer` 已处理的事件，忽略横向滚轮及 Shift 横向滚动；平滑滚动按 120 毫秒间隔识别新手势，翻页动画期间屏蔽重复翻页。

## 播放器菜单对照（2026-11-16）

菜单以当前 macOS 原项目 `OcPlayer/App/Shared/Features/Player/PlayerHUDActions.swift` 的五组根菜单和子菜单为准，信息面板、截图、分享分别对照 `PlayerHUDChrome.swift`、`PlaybackController+Screenshot.swift`、`PlayerScreen.swift`。Windows 使用 WinUI 3 `MenuFlyout`、`MenuFlyoutSubItem` 和原生单选/开关状态，保留用户已经确认的 HUD 布局及平台控件选择。

| 菜单 | macOS 条目与条件 | Windows 当前实现 |
| --- | --- | --- |
| 弹幕 | 启用、选择、重新匹配；已加载时显示时间偏移；不透明度、显示区域、字号、过滤与显示规则 | 对应入口齐备。偏移每次 ±0.5 秒及重置；不透明度/顶部显示区域各为 25%、50%、75%、100%；字号为小/标准/大/特大（18/22/26/30）；规则包含滚动、顶部、底部、合并重复、允许堆叠。另保留本地导入与完整弹幕设置入口。 |
| 字幕 | 字幕轨道子菜单（关闭及各轨道，外挂标记）、打开外挂字幕、字体大小子菜单 | 轨道由真实 native 选择状态驱动，外挂导入后更新菜单；字号每次 ±10%，范围 50%–300%，非 100% 时提供重置，并保存偏好。服务器外挂字幕接入沿用当前片源的鉴权。 |
| 音轨 | 列出音轨并标记当前项；无轨道时显示说明 | 使用真实轨道列表和选择接口，空状态显示“当前媒体无独立多音轨”。 |
| 章节 | 显示时间与名称、当前章节标记、点击跳转；无章节时显示空状态 | 从 Jellyfin `browse.chapters` 取得章节并转换时间单位，按播放位置更新当前项；另有加载中、错误及重试状态。与 macOS 一样，当前章节来源是服务器元数据；本地文件和直连地址没有该服务器数据时显示空状态。 |
| 更多/播放设置 | 播放速度子菜单、播放信息、全屏、画面截图；存在可分享地址时显示分享 | 六档倍速为 0.5/0.75/1/1.25/1.5/2×，并非整个设置菜单。已恢复信息、截图、条件分享；按用户明确选择，全屏仅保留在左上返回按钮旁，不重复放入设置。 |

播放信息层每秒刷新，独立于普通 HUD 显隐，包含播放状态/缓冲、进度、倍速、音量、章节数、视频分辨率/色彩/动态范围、音轨、字幕和八项内核计数。截图使用源尺寸，包含视频与字幕，不含弹幕或 HUD，PNG 保存到系统“图片/OcPlayer”；保存成功提示两秒。分享使用 Windows 系统分享面板，支持本地文件和可分享的公共 HTTP(S) 地址，依赖鉴权的媒体地址不显示分享入口。

菜单向按钮上方的窗口内侧展开，宽度最多 360 DIP；长轨道名、章节名和弹幕状态使用省略号并保留全文提示。实机已检查弹幕根菜单、规则子菜单和播放信息层。

Windows 默认 D3D11 renderer 已补上 SDR RGBA8 离屏截图，独立计算截图色彩参数，保留 HDR 播放交换链与输出模式。同时修复暂停时导入/重选字幕不刷新，以及关闭外挂字幕推进冻结画面的问题。2026-11-16 的 19 项 D3D11 测试、2 项暂停字幕回归及完整 216 项集成断言全部通过；真实 4K 视频验证了字幕导入、150% 字号、关闭、重选，以及截图像素和冻结时钟。补丁和复现命令见 [development.md](development.md#播放器菜单与原生截图)。系统分享目标的实际发送未执行。

## 需要明确的差异

1. macOS Liquid Glass 的系统材质及 SF Symbols 无法直接用于 Windows。当前使用半透明表面与相近 Fluent 图标；实时内容采样、折射和 macOS 一致的材质运动尚未实现。
2. 当前保留 Windows 原生右上角窗口按钮，因此顶栏右侧需要为这些按钮留位。macOS 左侧交通灯不属于 WinUI 原生窗口按钮。
3. 默认字体为 Windows 系统字体，字形和渲染与 macOS 不同。布局尺寸可对齐，文本不能保证逐像素相同。
4. 背景默认常开：整窗会话池覆盖首页、媒体库、观影、设置及子页；详情页固定进页快照，原始条目图加载成功后清晰与模糊图组一起淡入。WinUI Composition + Win2D 实时处理像素；这不代表卡片已经实现 Liquid Glass 的实时采样与折射。

这些都是当前状态或平台能力差异，不代表用户已接受相应取舍。
