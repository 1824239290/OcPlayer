# Windows 弹幕设置布局（2026-11-19）

参考上一轮 Bangumi 设置页的真实截图、`BangumiSettings.cs`，以及 macOS 的
`SettingsPagesDanmaku.swift`，将 Windows 独立弹幕设置页整理为紧凑分组布局。

- 第一组包含自动加载、显示弹幕、网关摘要及 anime-skip Client ID。
- 网关行右侧显示当前生效地址和“配置”按钮；地址与 API Key 在弹窗中编辑。
- 第二组包含内核渲染开关及下次播放生效的说明。
- 字号、不透明度、显示区域和五项过滤开关保留在“显示与过滤”折叠组。
- 使用 680 宽度上限、16 圆角、左右设置行、细分隔线和紧贴分组的说明。
  卡片、分隔线与说明通过 ThemeResource 跟随浅色、深色主题。

独立设置页的开关立即保存；Client ID 和数值离开输入框时保存对应字段。
所有自动保存均以最新已保存配置为基准，避免一起提交其他未完成的输入。
失败时恢复该字段并显示错误。网关弹窗点击保存才提交，取消不写入；地址校验
失败时弹窗保持打开。播放器弹幕设置仍使用显式“保存/取消”，保持原有语义。

最终 Debug 与隔离 Release 构建为 0 警告、0 错误。真实 WinUI/原生播放器
回归 42 条断言通过，新增覆盖实际播放器弹窗取消、网关错误地址、保存、取消、
页面重建后的地址摘要，以及显示数值的持久化。浅色、深色、640 像素窄窗口、
展开过滤组和两种弹窗均已检查截图。Release 启动探针通过，验证进程退出码为 0。
