# Windows 设置页统一布局（2026-11-19）

以 Bangumi 设置页和已确认的弹幕设置页为参考，统一其余设置页面的排版。修改位于 Windows 应用层，不改变共享核心或 liberika 播放内核。

## 共用样式

- 内容居中，最大宽度 680；窗口变窄时按可用空间缩小。
- 圆角 16 的主题卡片，左右内边距 16，设置行最小高度 42。
- 标签靠左，值和操作控件靠右；输入框、下拉框按行宽调整。
- 细分隔线缩进 24，说明采用主题次要文字颜色并跟在相关设置后面。
- 操作呈现为卡片里的文字行；清理、退出和恢复操作使用强调颜色。
- 卡片、分隔线和说明使用 ThemeResource，运行时切换浅色、深色和高对比主题会更新。
- 控件没有重复的 Header，使用 AutomationProperties.Name 保留可访问名称。

`Controls/SettingsUi.cs` 负责共用行、卡片、分组、操作和状态文字；`App.xaml` 定义样式，避免不同设置页分别写几何与配色。

## 页面

- 设置首页：统一分组间距、主题卡片；长状态文字按可用宽度换行。
- 媒体服务器：当前服务器与启动偏好分组，保留连接、管理、断开和默认服务器操作。
- 网络：User-Agent 横向输入行，保留明确的保存按钮。
- 播放：缓冲、跳过片头片尾、字幕、内核、主题按组排列；字幕外观默认折叠，颜色输入离开焦点后应用，保留颜色选择器和还原操作。
- TMDB：凭据、元数据偏好、镜像源分组；整库补全默认折叠，保留进度、取消、离开页面时取消和清除确认。
- MoviePilot：移除页面内重复的大标题；已连接状态显示账号与地址，未连接状态使用横向表单，保留记住密码与登录状态切换。
- 首页栏目：紧凑的上下箭头和开关；首尾移动按钮禁用，顺序和显示偏好照常保存。
- 维护：各类缓存容量左右对齐；清理操作与最近日志默认折叠；备份、恢复和诊断操作保留原有确认与文件选择流程。
- 关于：应用、共享核心和内核版本左右对齐，更新与链接独立分组。
- 开源许可证：按组件类型折叠，展开后显示紧凑可换行的操作行，阅读对话框适应窗口宽度。
- Bangumi：沿用原有账号与镜像布局，接入共用卡片和操作样式。

弹幕设置页保持先前确认的布局与保存行为；此次没有调整弹幕绘制、渲染选择或内核代码。
