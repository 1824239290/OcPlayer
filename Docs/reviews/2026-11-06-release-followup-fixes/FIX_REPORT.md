# 发版继续审查问题修复（2026-11-06）

上一轮新增的两处 P2 已修复，双端 App 全量测试通过。修复前的报告、失败探针、原图和代码完整保留在 `../2026-11-06-release-followup/` 及既有审查目录。

## 最终行为

MoviePilot 首页将订阅请求状态交给视图持有的 `MoviePilotSubscriptionLoader`，以配置/会话修订和请求代次共同判断归属。换服重置后立即允许新请求开始；即使旧请求不及时结束，其成功、失败及加载收尾也不能影响新请求。配置已变但视图任务尚未重跑时，旧结果同样被拒绝。取消保持静默，同一会话仍防止重复并发加载，失败或取消后可以重试。首页加载和重置都经过此生产加载器。

远程暂停回调改为显式暂停入口，先撤销音频中断的自动恢复意图，再根据当前状态决定是否调用引擎 pause。已暂停时不调用 toggle，也不播放；打开中的请求记录暂停意图，打开成功后执行。正常中断在系统允许且用户未明确暂停时仍自动恢复。

系统命令中心的暂停分派与测试使用同一个实例方法。控制器允许注入该命令中心，因此回归调用已安装的真实回调，不只测试一个独立判断函数。音频中断测试使用真实 AVAudioSession 通知类型及生产观察者，替身引擎用于核对 play/pause 调用。

## 回归与完整验证

新增 5 个控制器回归：普通远程暂停幂等、打开中远程暂停在成功后执行，以及 iOS 的明确暂停撤销自动恢复、无显式操作时正常恢复、无 shouldResume 时保持暂停。测试经过生产命令安装路径。新增用例在 macOS 执行 8 个，在 iOS 执行全部 11 个，均 Passed；逐条结果见 `macos-new-regressions.json`、`ios-new-regressions.json`。
