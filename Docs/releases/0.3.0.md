# OcPlayer v0.3.0 · 详情页翻页与播放稳定性、多服务器隔离、镜像设置

本次更新重点改善详情页浏览、播放稳定性和多服务器使用体验。

## 新增与改进

- iPhone / iPad 详情页采用翻页布局，完善海报展开、缩放返回与选集过渡。
- 播放支持多个候选源，打开失败时自动尝试其他可用源。
- Bangumi 与 TMDB 支持自填镜像地址；详情页可直接进入 MoviePilot 搜索找资源。
- 新增「一笔橘猫」启动动画，并改善冷启动内容和背景的衔接。
- 播放内核升级至官方 liberika v0.3.4，恢复内核弹幕渲染选项，并修复密集 CJK 字幕的纹理上限崩溃。

## 修复

- 修复退出播放后进度被旧响应覆盖、已看状态反转，以及续播位置不准确的问题。
- 修复切换服务器、登录与后台请求竞态；海报、头像、字幕与订阅列表按服务器和会话隔离。
- 修复 MoviePilot 换服后订阅漏加载、取消被显示为错误，以及旧请求覆盖新状态的问题。
- 修复来电等中断期间明确暂停后仍自动恢复播放；打开中的暂停命令也会被保留。
- 修复自动连播后关闭播放器失效、片尾误报播放错误，以及平滑滚轮下详情页无法返回的问题。
- 修复 iPhone 详情返回时标签栏闪现、独立搜索入口与头像颜色，以及窄屏操作按钮布局。

## 升级说明

- 首次升级会重新下载部分媒体图片，以建立正确的服务器缓存隔离；媒体元数据和播放进度继续保留。
- macOS 要求 macOS 26+、Apple Silicon；iPhone / iPad 要求 iOS 26+。
- macOS 提供 ZIP / DMG；iOS 提供 unsigned IPA，安装时需自行重签。
- 产物带 SHA-256 校验文件，并单独提供双端 dSYM 符号包。

发布于 2026-11-06。macOS 下载 `OcPlayer-v0.3.0-macOS-arm64.dmg` 或 ZIP；iOS 下载 `OcPlayer-v0.3.0-ios-unsigned.ipa`。
